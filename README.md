# Boardoza STM32F411 Black Pill Development Board

The **Boardoza STM32F411CEU6 Black Pill Development Board** is a compact development board based on the **STM32F411CEU6** microcontroller, featuring a **100 MHz Arm® Cortex-M4 core** that delivers strong processing performance in a small form factor. With its balanced architecture, the board is well suited for projects that require more capability than entry-level microcontrollers.

The board includes **512 KB Flash** and **128 KB SRAM**, provides **32 general-purpose I/O pins**, and supports common interfaces such as **UART, I²C, and SPI**. Programming and debugging are supported through **USB DFU** or **SWD** using tools like **ST-Link**, and the board is compatible with **STM32CubeIDE**, **PlatformIO**, and the **Arduino STM32 framework**, allowing flexible development workflows.

## Key Features

- **Arm® Cortex-M4 Core:** 32-bit Cortex-M4 processor running at up to 100 MHz, delivering strong performance for embedded applications.
- **Large On-Chip Memory:** Equipped with 512 KB Flash and 128 KB SRAM for complex and memory-intensive projects.
- **Rich Communication Interfaces:** Supports multiple interfaces including UART, I²C, SPI, and I²S.
- **Flexible Power Options:** Can be powered via USB Type-C or through 3.3V / 5V header pins.
- **Advanced Timers and PWM Support:** Suitable for motor control, LED driving, and precise timing applications.
- **Easy Programming and Debugging:** Supports USB DFU and SWD (ST-Link) programming and debugging.
- **Wide Software Compatibility:** Works with STM32CubeIDE, PlatformIO, and Arduino STM32 framework.

## Technical Specifications

**Model:** STM32F411CEU6  
**Manufacturer:** Boardoza    
**Manufacturer IC:** STMicroelectronics  
**Operating Voltage:** 3.3 V - 5 V (USB or external supply)  
**Voltage Input Type:** USB Type-C / 2.54 mm pin header  
**Core:** Arm® Cortex-M4 (32-bit with FPU)  
**Maximum Clock Frequency:** 100 MHz  
**Flash Memory:** 512 KB  
**SRAM:** 128 KB  
**GPIO Pins:** 32  
**Analog Inputs:** 10 (12-bit ADC)  
**Interfaces:** UART, SPI, I²C, I²S  
**Debug Interface:** SWD  
**Operating Temperature:** -40 °C to +85 °C  
**Board Dimensions:** 20.78 mm × 52.81 mm
